# 福利寮道馆

道馆任务固定只选择带“鑫”图标的福利寮，并在馆主阶段放弃突破。

## 流程

1. 按运行时间和星期设置进入道馆，读取游戏实际剩余次数。
2. 建立道馆按钮为灰色时直接筛选；可点击时先确认建立成功。
3. 只检查“鑫”图标和最低防守人数。刷新次数超过设定值后，人数门槛减半；达到20次仍未找到则结束当日任务并按推送配置发送提醒。
4. 集结时设置馆员攻击优先级和御魂，连续两次挑战仅在第一把切换御魂。
5. 进行馆员战。馆主阶段直接放弃突破；误入馆主准备或战斗页面时退出。
6. 有第二次机会时选择“再战道馆”，最多等待120秒识别到筛选页面后继续；最后一次保留赏金。
7. 奖励页面识别后等待1秒截图。任务自动结束时识别蓝票数量，按日期汇总本次任务的所有截图并推送；发送成功后删除截图，关闭推送或发送失败时保留。

## 配置

保留运行时间、星期限制、馆员攻击优先级、馆员战斗和御魂配置、每日挑战次数、最低防守人数、降低人数要求的刷新次数、结算截图开关和推送开关。

推送开关在本任务的「推送配置」里，实际渠道沿用全局「脚本错误处理」的推送配置。结算截图作为邮件附件发送，渠道需为 smtp：QQ 邮箱填 `host: smtp.qq.com`、`port: 465`、`user: 发件邮箱`、`password: SMTP授权码`（授权码在邮箱设置里开启 SMTP 服务后生成，不是登录密码），`To` 不填表示发给发件邮箱自己。其它渠道发不了附件，只会推送文字汇总，发送成功后截图同样会被删除。
